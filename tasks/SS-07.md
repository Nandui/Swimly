## Problem
The desk class page breadcrumb reads 'Otters › Class'. The H1 is itself a link back to the class and contains the 'Covered' tag, so its accessible name is 'OttersCovered'. Only 'Week before' shows on today's class, so the actions shift between dates.

## Change (original)
BackLink to the class ('‹ Otters'). PageHeader with a plain-text H1 (the class name) and its tags in the PageHeader meta row. Render a disabled 'Week after' on the latest date so the actions stay put. The steps are already SegmentedLinks (SYS-06).
