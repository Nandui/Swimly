## EXTRA from the lead (verified live)
The refund request form (src/components/refunds/request-form.tsx, <form className="refund-request-form">) has no method, so a submit that reaches the browser before React handles it (slow hydration, a script error) sends the customer's name, contact details and reason as a GET query string into the URL, browser history and server logs. Give every JS-handled form that carries personal data method="post" (keeping onSubmit preventDefault) so it can never fall back to GET. Grep the app for <form elements without a method that hold personal fields (refunds, swimmer add/edit, staff, HR notes, rota absences, details changes) and fix them all; search/filter forms that are meant to be GET stay GET.
