- KEEP: The change is needed and nothing in it is impossible to fix. But eight of its instructions would break something if built as written. Evidence for each:

(1) Lint failure. "Plain <button> CollapsibleTrigger" and "History collapsible triggers are plain buttons" would fail `npm run lint`. eslint.config.mjs uiSyntax (lines 11-14) bans a literal JSX <button> in every src/**/*.tsx file outside shadcn, and the Activities block repeats that rule.

(2) SegmentedChoice does not exist. It has zero hits in src, docs and DESIGN.md. If it is built in a module with <button>, lint fails. If it is built on .pc-seg, nothing shows as selected: .pc-seg-item styles only [aria-current] (poolside.css:613-614), not aria-pressed.

(3) The section tabs would overflow at 375. Deleting .tabs (flex-wrap) and the 105-107 rule leaves the line-variant TabsList at h-9 with 35px triggers and no wrap. I measured live with alex at 375: the 6 triggers total 656px. With the default (segmented) variant and no wrap the list is 684px, and the document scrollWidth is 700 against a 375 viewport. That is horizontal page scroll, which DESIGN.md:202-203 forbids.

(4) Utility classes lose to .pc-row. The pc-row rules (poolside.css:523-541) are unlayered, outside @layer base (198-201) and @layer components (421-427), so they beat any Tailwind utility. On a .pc-row element these would all be overridden by display:flex, align-items:center, a 1px line border and a surface background: items-stretch, the rowLayout `grid` in the class picker, bg-ui-brand-soft for the selected class, hover:bg-*, and border-2 or border-primary for the current chapter. Result: chapter children shrink and centre, picker columns misalign with the header, and the selected class gets no highlight.

(5) The loading skeleton would break. src/app/(activities)/students/[id]/loading.tsx imports swimmer-profile.module.css and sizes its avatar Skeleton with styles.avatar. Deleting .avatar collapses it to 0x0.

(6) The chapter would squeeze into 72px. Deleting .year and the ::before/::after rules but keeping .chapterRow (grid-template-columns 4.5rem 1fr) drops the Collapsible into the 72px first column once the <time> is removed.

(7) Medical notes would read "Not recorded". getStudent redacts through classifyMedical (students.ts:161), so a viewer without access gets medicalNotes null and hasMedicalNotes true.
