## Problem
Home's 'All training/reading/shifts' links are 22px underlined text. The shared review is a plain card, not the yellow first row. Notices are colour only, with no icon, and use role=status even on load. Loading is the word 'Loading…', and Home loses its H1 while loading or on error. A failed HR read shows 'Loading…' forever with no Try again. Empty lists are floating sentences, or blue info Notices on HR. The pending details form looks fully active. The certificate picker is the native grey 'Choose file' (light even in dark). More rows have bare, misaligned icons. Reminder options are plain 500 labels with silent saves. A document code block scrolls the page sideways (626px at 375); prose is 15px. The code field is 56px with letter-spacing, and the HR code step drops the confirm panel. Icons differ from the mockups (Mail, Check, Upload, ArrowLeft) and back links are inset 16px. The qualifications form always shows the 'something else' field. Details has no avatar row or heading and a single-line note. Every tab reads 'Turnfin Me'. en-IE dates give 'Mon, 12 Oct' and 'Sept'. Copy names LeisureWorld. The manifest uses the retired teal and grey with a single transparent 'any' icon. Frame titles and H1s disagree ('Training' versus 'My training'). Eight inline style objects use literal sizes. There is no not-found or error page.
