## Problem
refunds.css:36-37 has a comment inside a selector, compiling to '.turnfin-refunds .turnfin-refunds .refund-list', so the white list panel never renders and rows sit transparent on the canvas (1.10:1 edges). Filters are six large fields in a separate panel with a second primary 'Apply filters' and an always-visible Reset; on phones the first result starts at about 1,250px. Rows stack four lines with a reference 'eyebrow', are 96px or taller and end in ArrowRight. Summary tiles are hand-styled (.refund-summary), with full-ink zeros and a dev note 'Totals follow…'. 'Awaiting review' counts SUBMITTED plus IN_REVIEW but links to SUBMITTED. The header, empty state and pagination are hand-rolled. No page-bar item is current on New request, request pages or tile views. The H1 stays 'Refund requests' under My drafts and My requests. Copy: the tagline names the tenant ('…across LeisureWorld'); four names for the create action; 'No requests to show' for every empty view, plus a redundant '0 requests'. The status select mixes views and statuses in one list. The placeholder is clipped at 375 and has no icon. Refunded uses CheckCheck on the tile and Check on the tag. Spacing between blocks is 16, 49 and 26px. docs/refunds.md still describes teal, aqua, a sidebar cookie and its own theme.
