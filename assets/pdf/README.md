# Fonts for PDF documents

`Manrope_500Medium.ttf` and `Manrope_800ExtraBold.ttf` are Manrope, the app's type family (DESIGN.md, Type), copied unchanged from the npm package `@expo-google-fonts/manrope` 0.4.3 on 23 November 2026. They are licensed under the SIL Open Font License 1.1 (`OFL.txt`).

The incident report PDF (`src/modules/incidents/features/export/server/pdf.ts`) embeds them. Keep `next.config.ts`'s output tracing entry for this folder when moving them.
